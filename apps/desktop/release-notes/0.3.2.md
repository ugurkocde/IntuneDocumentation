## Improved

### Search settings
- **Refreshing your data keeps your search.** When a new collection finishes while Search settings is open, the results update in place. Your query and filters are only cleared when you sign out or switch tenant.
- **Clear recovery when a search fails.** An error now offers Try again, or Collect when there is no collection yet.
- **Filters stay visible.** Selected family and platform filters are always shown, also while a search runs. When filters hide every match, the page says how many settings match without them and offers Clear filters.
- **Long values are readable.** Long values such as certificates or XML can be expanded with Show full value, and every value can be copied.
- **Tidier results.** Long family lists collapse behind More, the search box stays visible while you scroll, and single letters are no longer highlighted.

## Fixed
- Screen readers now announce when a search is running and read the new match count instead of the previous one.
- Result cards no longer appear as separate page regions to assistive technology.
